PROJEK HTML PROFESIONAL — NEXA STUDIO

Isi:
- index.html: landing page responsif dengan CSS dan JavaScript di dalam satu file.

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka index.html di browser modern (Chrome, Edge, Firefox, atau Safari).

Catatan:
- Proyek ini tidak membutuhkan instalasi atau koneksi internet untuk layout utamanya.
- Formulir kontak menggunakan aplikasi email perangkat (mailto), bukan backend. Ganti alamat hello@nexastudio.example dengan email Anda sebelum dipublikasikan.
- Nama, statistik, proyek, dan testimoni merupakan konten contoh yang dapat Anda sesuaikan.
